# Excel-Salary-Dashboard
Interactive Excel dashboard analysing the salary differences around the world for different jobs in the data analytics industry.
### Dashboard preview

## Project Overview
This dashboard was created to identify the differences in salaries around the world in the data analytics industry. Analysis was performed using real-world data. 
### [click here to view the raw data]([Data Set.xlsx](https://github.com/user-attachments/files/33102740/Data.Set.xlsx)
### Dashboard features
- Different fields in the data analytics industry
- World map 
- Different types of job (full-time vs part time)
